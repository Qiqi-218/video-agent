# 需求范围

定位：单人自用、面向开发者的本地视频 Agent。它服务于已经会配置模型、命令行和开发环境的用户，优先通过 CLI/API 被已有编程 Agent 调用，Web 用于预览和手动微调。

## MVP 用户旅程

1. 登记多段本地视频，得到资产 ID、元数据和缩略图。
2. 用自然语言描述成片结构，例如“做一个 60 秒活动回顾，现场开头，互动居中，合影收尾”。
3. Agent 查询已有证据，生成带来源时间的候选片段和 TimelineRevision。
4. 用“替换第二段”“缩短开头”“锁定结尾”等命令提交局部修改。
5. 查看 revision 差异，撤销或恢复版本，生成预览和真实 MP4。
6. 任务中断后可以继续；导出只有通过 ffprobe 和完整解码检查后才算完成。

## MVP 范围

- 3–10 个本地 MP4/MOV，总素材时长先限制在 30 分钟内。
- 一条主视频轨、一个可选 BGM 轨和字幕层。
- 裁剪、替换、删除、插入、重排、锁定、撤销和恢复。
- 字幕/ASR 和代表帧分析，按来源时间返回证据。
- 16:9、9:16、fit/crop。
- CLI/API JSON 输出；后续增加 MCP。
- 复用 GoClip 的 SQLite、任务、FFmpeg、字幕和现有 Web 播放器。

## 不在 MVP

生成式视频、自动发布、多人协作、账号/计费、复杂多机位、专业调色、复杂动画和任意脚本执行。

## 验收

- 两段不同帧率/方向的素材可以实际导出并完整解码。
- 每个成片片段都能追溯到资产和源时间范围。
- 旧 revision 提交被拒绝，锁定片段不能被修改，重复 operation ID 不重复提交。
- 连续 5 次局部修改后工程仍可恢复。
- 素材不匹配时返回 `no_match` 或澄清，不创建虚构片段。
- 首轮真实试用选 8 个任务，至少 7 个不需要改代码即可完成；稳定后扩展到 20 个任务，目标 17 个完成。
