# 产品定义

## 一句话定义

Video Agent 是一个面向开发者的本地视频 Agent 工具链：它让 Codex、Claude Code 等 Code Agent 可以通过 CLI、API 或 MCP，以结构化、可追溯、可恢复的方式完成视频素材分析、时间线编辑和媒体导出。

它不是剪映的替代品，也不是通用的 Code Agent。它是一个被 Code Agent 调用的视频领域执行层。

## 分层定位

```text
用户自然语言
      ↓
Code Agent：理解需求、规划步骤、选择工具
      ↓ CLI / API / MCP
Video Agent：分析素材、管理时间线、执行编辑、渲染验证
      ↓
本地视频文件与可审阅产物
```

- Code Agent 负责“应该怎么剪”。
- Video Agent 负责“按照约束把它可靠地剪出来”。
- CLI、API 和 MCP 是调用入口，不是产品本身的智能核心。

## 目标用户

首要用户是单人开发者、内容工具开发者和熟悉命令行的创作者。他们愿意配置模型和本地环境，更看重自动化、可重复、可调试和能接入现有开发工作流，而不是完整的消费级特效生态。

## 解决的问题

传统视频编辑器适合人手动操作，但不适合让编程 Agent 稳定地完成连续修改：模型很难知道片段来自哪里，局部修改容易破坏其他内容，导出任务也缺少可验证的状态。

Video Agent 把视频编辑变成一种受约束的工程操作：素材有 ID，片段有源时间范围，时间线有 revision，修改有 operation ID，导出有任务状态和产物校验。

## 核心价值

1. **可编排**：Code Agent 可以用自然语言驱动结构化视频工具。
2. **可追溯**：每个成片片段都能追溯到源资产和时间范围。
3. **可局部修改**：修改“第二段”“开头”“被锁定的结尾”，而不是每次重做整条片子。
4. **可恢复**：revision、撤销和幂等操作让连续编辑不会失控。
5. **可验证**：只有真实媒体产物通过元数据和完整解码检查，任务才算完成。

## 产品边界

### 首先做好

- 多素材导入和内容证据
- 字幕/ASR、代表帧和片段检索
- 裁剪、替换、删除、插入、重排和锁定
- 16:9、9:16、基础字幕和简单 BGM
- 版本化时间线、预览、导出和失败恢复
- CLI/API 优先，工具稳定后提供 MCP

### 暂时不做

- 复刻剪映的模板、贴纸、特效和素材商城生态
- 面向大众的完整可视化剪辑器
- 生成式视频、自动发布、账号和计费体系
- 复杂调色、多机位、任意脚本执行和专业动画系统

## 与剪映的差异

剪映的优势是功能广度、交互成熟度和内容生态；Video Agent 的切入点是视频编辑的可编程性和工程可靠性。我们不以“比剪映功能更多”为目标，而以“让 Code Agent 能可靠修改视频”为目标。

适合展示的任务包括：

- “删掉所有停顿超过一秒的片段。”
- “保留嘉宾讲话，但缩短到十秒。”
- “找出所有关于价格的回答并拼成一段。”
- “只替换第二段，其他内容保持不变。”
- “恢复到导出前的版本，并告诉我每段素材的来源。”

## 参赛表达

推荐表述：

> 我们不是在做另一个剪映，而是在做视频编辑的 API 和 Agent 运行时。剪映解决的是人手动编辑视频；Video Agent 解决的是开发者和 AI 如何可靠、可追溯地编辑视频。

参赛演示应围绕一个闭环展开：多段真实视频 → 自动分析和检索 → 生成有来源的时间线 → 局部自然语言修改 → 导出并验证 MP4。不要把尚未实现的特效生态或通用对话能力作为承诺。
